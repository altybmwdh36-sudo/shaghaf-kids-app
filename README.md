# منصة «شَغَف»

تطبيق Flutter عربي للتعلم والمعرفة والترفيه الهادف، مع تسجيل دخول عبر رمز تحقق، وربط Supabase، ومكتبة فيديو لا تعرض للمشتركين إلا الفيديوهات التي نُشرت بعد مراجعة المدير.

## ما هو موجود في المستودع
- تسجيل حساب بالبريد الإلكتروني أو SMS عبر Supabase Auth.
- ربط حساب المشترك بجهاز نشط واحد عبر معرف تثبيت محفوظ في التخزين الآمن.
- محتوى معرفي نصي مدمج داخل التطبيق، ومكتبة فيديو تقرأ الفيديوهات المنشورة من Supabase.
- مشغل فيديو يدعم روابط MP4/HLS المباشرة المتوافقة، مع التنقل الرأسي بين المقاطع.
- ملاحظات ومحتوى صوتي محلي باستخدام تحويل النص إلى كلام.
- لوحة إدارة للمشرف لإدارة الفيديوهات والتعليقات والبلاغات والإعدادات والإحصاءات.
- كل فيديو يُضاف يدوياً أو يُكتشف آلياً يبدأ بحالة `pending` ولا يظهر للمشتركين قبل موافقة المدير.

## اكتشاف الفيديوهات
يوجد تكامل أولي مع **NASA Image and Video Library** و**Wikimedia Commons** عبر Supabase Edge Function:
- البحث في أقسام الفضاء والعلوم والطبيعة والتقنية.
- التحقق من أن رابط الفيديو مباشر ومن نطاق أصول NASA.
- منع إدراج الروابط المكررة قدر الإمكان.
- إرسال المرشحين إلى قائمة المراجعة، دون نشر تلقائي.
- يستطيع المدير بدء البحث من لوحة الإدارة بعد نشر الوظيفة على Supabase.
- الترخيص لا يثبت ملاءمة الفيديو للأطفال؛ كل النتائج تظل قيد المراجعة حتى يفحصها المدير ويوافق عليها.

راجع [دليل إعداد الخادم](docs/ADMIN_BACKEND_SETUP.md).

## ما لم يكتمل بعد
- إضافة مصادر فيديو متعددة ومتنوعة خارج NASA.
- خدمة ذكاء اصطناعي متخصصة لفحص النص والصوت والصورة والمحتوى المرئي؛ البحث الحالي ليس شهادة سلامة.
- جدولة عمليات الاكتشاف الدورية دون تدخل المدير.
- اختبار شامل على أجهزة Android فعلية، والتحقق من إعدادات البريد وSMS الفعلية في مشروع Supabase.
- استكمال تجربة المستخدم النهائية ومراجعة الخصوصية والامتثال قبل الإطلاق العام.

لا يمكن لأي فلترة آلية أن تضمن منع كل محتوى غير ملائم. لذلك تبقى المراجعة البشرية والبلاغات وموافقة المدير ضرورية، خصوصاً لأن المنصة تستهدف الأطفال واليافعين.

## بناء Android
يتطلب Flutter stable ومفتاح Supabase العام:
```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
```

لا تضع مفتاح `service_role` أو كلمات مرور المدير أو مفاتيح مزودي الذكاء الاصطناعي داخل التطبيق أو المستودع. تحفظ الأسرار في بيئة الخادم فقط.
