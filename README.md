# منصة «شَغَف» للأطفال والنشء حتى 20 سنة

منصة تربوية وتعليمية وقيمية متكاملة مبنية بـ **Flutter** مع **سكربت Python للجلب والفلترة التلقائية**.

## أبرز المزايا المنفذة
1. **اشتراك مجاني مفعّل تلقائياً ضمن الدخول:** تفعيل فوري للاشتراك المجاني عند تسجيل الدخول وحفظ الجلسة محلياً، مع دعم وضع المالك والمشرف.
2. **أقسام تربوية وتعليمية ومهارية شاملة (حتى 20 سنة):**
   - أناشيد وقرآن
   - قصص الأنبياء والصحابة
   - مبادئ وأخلاق
   - الثقة بالله والإيمان وحب الآخرين
   - علوم وثقافة
   - المذاكرة وحب الدراسة والاختراع
   - بناء الشخصية والقيادة والإقناع والنجاح
   - فكاهة هادفة وبريئة
3. **فلترة احترافية صارمة:** فحص ومطابقة حقيقية للدين والإيمان والقيم والمبادئ والأخلاق الحميدة والتعليم وبناء المدارك، وحجب المحتوى المخالف أو المسيء أو الاحتيالي.
4. **ربط مباشر بالنت وتبويبات متكاملة:**
   - تبويب **الأقسام** مع بحث فوري وزر «بحث بالنت» لكل قسم.
   - تبويب **ديليز** للمقاطع القصيرة بتمرير رأسي سريع.
   - تبويب **المفضلة** لحفظ المقاطع المفضلة.
   - تبويب **السجل** لتتبع ما تمت مشاهدته مع إمكانية المسح.
   - **لوحة الإشراف والفلترة الاحترافية** لمتابعة نسب المطابقة والركائز المحققة.

## خطوات التشغيل السريعة
```bash
flutter pub get
flutter run
```

لتحديث ملف البيانات المفلتر عبر سكربت بايثون:
```bash
cd scripts
python auto_fetch_clean_videos.py
```
